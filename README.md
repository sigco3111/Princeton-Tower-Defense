**Princeton Tower Defense**는 React, Canvas 2D, Next.js로만 구현된 풀 브라우저 기반의 정통 타워 디펜스 게임입니다. 5개의 정교한 바이옴 지역에 걸친 Princeton 캠퍼스 컨셉의 26개 레벨, 9명의 플레이어블 영웅, 전술 주문, 그리고 진짜로 머리를 써야 하는 듀얼 레인 압박 맵에서 Princeton 테마의 타워, 영웅, 적들과 함께 싸웁니다.

## 🎮 게임 소개

프린스턴 타워 디펜스는 브라우저에서 즐기는 무료 전략 게임입니다. 학술 스트레스 몬스터의 물결로부터 프린스턴대학교 캠퍼스를 방어하세요. 모든 요소 — 타워, 적, 지형, 이펙트, UI 오버레이 — 가 코드로 직접 그려지고 애니메이션됩니다. 스프라이트 시트도, 게임 엔진도 없습니다. 전체 렌더링 파이프라인(이소메트릭 지형, 타워 애니메이션, 발사체 궤적, 사망 이펙트, 안개, 신광선, 환경 파티클)은 손으로 작성된 Canvas 2D 코드입니다. 정적 레이어는 오프스크린 캔버스에 캐시되며, 품질 인지 렌더링은 런타임 성능에 따라 디테일을 조정합니다.

## ✨ 주요 특징

### 🏛️ 7개의 분기형 업그레이드 타워

각 타워는 고유한 역할과 두 가지 최종 업그레이드 경로를 가지며, 경로마다 동작이 완전히 달라집니다.

| 타워 | 역할 | 업그레이드 경로 |
|---|---|---|
| **나소 캐논** | 중포병 | 기관총 / 화염방사기 |
| **파이어스톤 도서관** | 감속 + 제어 | 이쿼드 분쇄기 / 블리자드 |
| **이쿼드 연구소** | 연쇄 마법 DPS | 집중 빔 / 체인 라이트닝 |
| **블레어 아치** | 음파 크레센도 | 충격파 사이렌 / 심포니 홀 |
| **이팅 클럽** | 경제 | 투자 은행 / 모집 센터 |
| **딩키 정거장** | 부대 소환 | 켄타우로스 궁수 / 중장 기병 |
| **팔머 박격포** | 공성 광역 | 미사일 배터리 / 잿불 용광로 |

### 🦸 9명의 플레이어블 영웅

| 영웅 | 스타일 | 능력 |
|---|---|---|
| **프린스턴 호랑이** | 근접 격투가 | *장엄한 포효* — 광역 기절 + 공포 |
| **아카펠라 테너** | 원거리 지원 | *고음* — 음파 폭발 + 아군 치유 |
| **매시 기사** | 탱커 | *요새 방패* — 무적 + 도발 |
| **로키 라쿤** | 원거리 포격 | *바위 강타* — 대규모 광역 피해 |
| **F. 스콧** | 버퍼 | *영감의 환호* — 타워 피해/사거리 증가 |
| **머서 장군** | 지휘관 | *기사 소집* — 3명의 중장 기병 소환 |
| **BSE 엔지니어** | 유틸리티 | *포탑 배치* — 자동 방어 포탑 |
| **아이비 수호자** | 자연의 화신 | *자연의 변환* — 두 가지 형태로 변환 |
| **덩굴** | 소환수 | 자연의 힘으로 적을 휘감고 압도 |

### 🔮 주문, 환경 위험 요소, 챌린지 규칙

- **6개의 시전 가능한 주문** — 화염구, 번개, 빙결, 주문 방어막, 보급일, 증원. 각각 별점으로 업그레이드 가능.
- **맵 환경 위험** — 용암 웅덩이, 소택지, 블리자드 구역, 그리고 지역별 목표를 추가하는 특수 구조물(금고, 신전, 병영, 비콘).
- **챌린지 맵** — 비표준 전략을 강제하는 타워 제한과 다중 목표 점수 시스템.

### 🗺️ 월드맵과 진행 시스템

영역 노드, 별 게이트 진행, 그리고 캠페인 개요를 갖춘 완전한 인터랙티브 월드맵. 레벨에서 획득한 별이 새로운 영역, 챌린지 맵, 주문 업그레이드를 해제합니다.

## 🚀 시작하기

### 필수 조건

- **Node.js** 18 이상
- **pnpm** (권장 패키지 매니저)

### 설치

```bash
git clone https://github.com/sigco3111/Princeton-Tower-Defense.git
cd Princeton-Tower-Defense
pnpm install
```

### 개발 모드

```bash
pnpm dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 플레이하세요.

### 프로덕션 빌드

```bash
pnpm build    # 정적 export → out/
pnpm serve    # out/ 로컬 서빙 (선택)
```

### 린트

```bash
pnpm lint
```

### 환경 변수

| 변수 | 설명 |
|---|---|
| `NEXT_PUBLIC_TD_DEV_PERF` | `"1"`로 설정하면 개발 성능 오버레이 활성화 (Ctrl+Shift+P로 토글) |

이것이 유일한 환경 변수입니다. 게임은 `.env` 설정 없이도 동작합니다.

## 🗼 타워 (7종)

### 나소 캐논 (Nassau Cannon)
**역할**: 중포병 — 지상 적에 강한 단일 대상 피해

| 레벨 | 설명 |
|---|---|
| 1단계 | 기본 캐논 — 단발 포격 |
| 2단계 | 강화 캐논 — 더 큰 구경 (1.5배 피해) |
| 3단계 | 중형 캐논 — 안정화된 포신 (2.2배 피해) |
| 4단계 | 선택: 기관총 또는 화염방사기 |

- **기관총**: 빠르게 발사하는 기관총 (8배 공격 속도, 0.4배 단발 피해)
- **화염방사기**: 지속적인 화염 사격 (지속 피해)

### 파이어스톤 도서관 (Firestone Library)
**역할**: 감속 + 제어 — 마법 폭발 피해

| 레벨 | 설명 |
|---|---|
| 1단계 | 기본 도서관 — 단일 대상 감속 |
| 2단계 | 강화 도서관 — 광역 감속 (40% 감속 + 마법 피해) |
| 3단계 | 고위 도서관 — 60% 감속 + 1.8배 피해 |
| 4단계 | 선택: 이쿼드 분쇄기 또는 블리자드 |

### 이쿼드 연구소 (E-Quad Lab)
**역할**: 연쇄 마법 DPS

| 레벨 | 설명 |
|---|---|
| 1단계 | 기본 연구소 — 3체인 |
| 2단계 | 강화 연구소 — 4체인 |
| 3단계 | 고위 연구소 — 5체인 |
| 4단계 | 선택: 집중 빔 또는 체인 라이트닝 |

### 블레어 아치 (Blair Arch)
**역할**: 음파 크레센도

| 레벨 | 설명 |
|---|---|
| 1단계 | 크레센도 — 최대 4중첩까지 축적 |
| 2단계 | 공명 — 최대 6중첩, 1.4배 피해 |
| 3단계 | 포르테 — 최대 8중첩, 1.8배 피해 |
| 4단계 | 선택: 충격파 사이렌 또는 심포니 홀 |

### 이팅 클럽 (Eating Club)
**역할**: 경제 — 골드 생성 타워

| 레벨 | 설명 |
|---|---|
| 1단계 | 기본 클럽 — 200 골드/라운드 |
| 2단계 | 강화 클럽 — 350 골드/라운드 |
| 3단계 | 고위 클럽 — 500 골드/라운드 |
| 4단계 | 선택: 투자 은행 또는 모집 센터 |

### 딩키 정거장 (Dinky Station)
**역할**: 부대 소환

| 레벨 | 설명 |
|---|---|
| 1단계 | 기본 정거장 — 보병 소환 |
| 2단계 | 강화 정거장 — 궁수 소환 |
| 3단계 | 고위 정거장 — 기사 소환 |
| 4단계 | 선택: 켄타우로스 궁수 또는 중장 기병 |

### 팔머 박격포 (Palmer Mortar)
**역할**: 공성 광역

| 레벨 | 설명 |
|---|---|
| 1단계 | 기본 박격포 — 광역 포격 |
| 2단계 | 강화 박격포 — 더 큰 폭발 반경 |
| 3단계 | 고위 박격포 — 더 큰 피해 |
| 4단계 | 선택: 미사일 배터리 또는 잿불 용광로 |

## 🦸 영웅 (9명)

### 프린스턴 호랑이 (Princeton Tiger)
- **스타일**: 근접 격투가
- **능력**: *장엄한 포효* — 광역 기절 + 공포
- **설명**: 캠퍼스의 상징. 엄청난 광역 포효 능력으로 적들을 혼란에 빠뜨립니다.

### 아카펠라 테너 (Acapella Tenor)
- **스타일**: 원거리 지원
- **능력**: *고음* — 음파 폭발 + 아군 치유
- **설명**: 음파의 힘으로 적을 공격하고 아군을 치유합니다.

### 매시 기사 (Mathey Knight)
- **스타일**: 탱커
- **능력**: *요새 방패* — 10초간 무적 + 도발
- **설명**: 매시 홀의 수호자. 요새처럼 버티며 모든 적의 주의를 끕니다.

### 로키 라쿤 (Rocky Raccoon)
- **스타일**: 원거리 포격
- **능력**: *바위 강타* — 대규모 광역 피해
- **설명**: 거대한 바위를 던져 적 무리를 한 번에 쓸어버립니다.

### F. 스콧 (F. Scott)
- **스타일**: 버퍼
- **능력**: *영감의 환호* — 타워 피해/사거리 증가
- **설명**: 문학적 영감을 불어넣어 아군 타워의 능력을 강화합니다.

### 머서 장군 (General Mercer)
- **스타일**: 지휘관
- **능력**: *기사 소집* — 3명의 중장 기병 소환
- **설명**: 전설의 화염에 휩싸인 지휘관. 충직한 기사들을 자신의 깃발 아래로 소환합니다.

### BSE 엔지니어 (BSE Engineer)
- **스타일**: 유틸리티
- **능력**: *포탑 배치* — 자동 방어 포탑
- **설명**: 공학 도서관에서 설계한 자동 포탑을 배치하는 brilliant 발명가. 커피가 더 필요합니다.

### 아이비 수호자 (Ivy Warden)
- **스타일**: 자연의 화신
- **능력**: *자연의 변환* — 두 가지 형태로 변환
- **설명**: 프린스턴의 고딕 탑을 뒤덮은 아이비를 구현한 고대 수호령. 살아있는 덩굴을 조종하여 적을 휘감고 으스러뜨립니다.

### 덩굴 (Vine)
- **스타일**: 소환수
- **설명**: 자연의 힘으로 적을 휘감고 압도합니다.

## 🔮 주문과 환경 효과

### 6개의 시전 가능한 주문

| 주문 | 효과 |
|---|---|
| **화염구** | 광역 화염 피해 |
| **번개** | 연쇄 전기 피해 |
| **빙결** | 광역 빙결 — 적을 얼려 움직임을 멈춤 |
| **주문 방어막** | 모든 적에게 광역 디버프 |
| **보급일** | 즉시 골드 획득 |
| **증원** | 임시 영웅 부대 소환 |

각 주문은 별점으로 업그레이드할 수 있습니다.

### 환경 위험

- **용암 웅덩이**: 화산 지역에서 발견. 가만히 서 있는 적에게 지속 피해.
- **소택지**: 습지에서 발견. 적의 이동 속도를 감소.
- **블리자드 구역**: 겨울에서 발견. 적의 이동 속도를 크게 감소.
- **특수 구조물**: 금고, 신전, 병영, 비콘 — 지역별 목표를 추가.

### 챌린지 맵

## 🏗️ 아키텍처 개요

### 게임 루프

중앙 오케스트레이터는 `usePrincetonTowerDefenseRuntime` (`hooks/usePrincetonTowerDefenseRuntime.tsx`)입니다. 최상위 게임 상태를 소유하고 매 프레임 두 개의 주요 모듈에 작업을 위임합니다:

1. **시뮬레이션** — `runtime/updateGame.ts`가 모든 게임 상태를 진행: 적 이동, 타워 타겟팅, 발사체 물리, 상태 효과, 위험 요소 틱, 웨이브 생성, 승패 조건.
2. **렌더링** — `runtime/renderScene.ts`가 현재 상태를 다중 레이어 Canvas 2D 파이프라인에 그립니다.

`hooks/runtime/`의 지원 런타임 모듈은 카메라 제어, 입력 이벤트, 주문 실행, 줌/제스처, 건설 드래그 상호작용, 웨이브 미리보기, 튜토리얼 콜백을 처리합니다.

### 상태 관리

모든 게임 상태는 React 훅(`useState`, `useRef`)과 가변 엔티티 컬렉션에 살고 있습니다. 외부 상태 관리 라이브러리(Redux, Zustand, Jotai 등)는 사용하지 않습니다. 영속 데이터(캠페인 진행, 설정, 커스텀 레벨)는 타입화된 래퍼를 통해 `localStorage`에 직렬화됩니다.

### Canvas 2D 렌더링 파이프라인

렌더링은 다중 레이어 캐싱 전략을 사용합니다:

- **정적 맵 레이어** — 지형, 경로, 기본 장식이 한 번 렌더링되어 오프스크린 캔버스에 캐시되며, 줌이나 리사이즈 시에만 다시 그려짐.
- **장식 레이어** — 바이옴 소품(나무, 바위, 구조물)이 별도로 캐시됨.
- **안개와 분위기** — 안개와 분위기 효과가 전용 레이어에 그려짐.
- **엔티티 레이어** — 타워, 적, 영웅, 발사체, 파티클이 매 프레임 다시 그려짐.
- **UI 오버레이** — 사거리 표시기, 건설 메뉴, 체력 바가 마지막에 합성됨.

품질 인지 렌더링은 프레임 드롭을 감지하고 런타임에 장식 밀도, 파티클 수, 효과 복잡도를 줄입니다.

## ⚠️ 확장성 위험과 알려진 한계

### 1. `updateGame.ts` 신 함수

`runtime/updateGame.ts`는 단일 파일이 **5,000줄을 초과**합니다. 적 이동, 타워 타겟팅, 발사체 업데이트, 상태 효과, 웨이브 생성, 위험 요소 틱, 승패 평가를 한 함수에서 처리합니다. 이는 시뮬레이션을 테스트, 추론, 독립적으로 확장하기 어렵게 만듭니다. 도메인별 업데이트 모듈(이동, 전투, 생성, 점수)로 분할되어 파이프라인을 구성해야 합니다.

### 2. `renderDecorationItem.ts` 모놀리스

장식 렌더링 파일이 **33,000줄을 초과**하며 장식 유형에 따라 dispatch하는 거대한 switch/case를 포함합니다. 모든 바이옴의 나무, 바위, 구조물, 소품이 한 파일에 인라인되어 있습니다. 각 장식 유형이 자신의 그리기 함수를 등록하는 레지스트리 패턴으로 리팩토링해야 합니다.

### 3. 전역 가변 레지스트리

`LEVEL_DATA`와 `MAP_PATHS`는 커스텀 레벨이 런타임에 쓰는 모듈 레벨 가변 객체입니다. 이는 커스텀 레벨을 로드하는 것이 모든 소비자에게 보이는 전역 상태를 변경한다는 것을 의미하며, 암묵적 결합을 만들고 여러 게임 인스턴스를 실행하거나 서버 사이드 렌더링을 추가하는 것을 안전하지 않게 만듭니다. 불변 데이터 레이어나 범위 컨텍스트로 교체해야 합니다.

### 4. 고정 파티클과 이펙트 풀

파티클 시스템과 시각 효과는 고정 크기 풀을 사용합니다. 긴 세션이나 적 밀도가 높은 레벨에서는 풀이 소진되어 효과가 조용히 누락될 수 있습니다. 풀 크기를 동적으로 조정하거나 우선순위 기반 축출로 우아하게 저하해야 합니다.

### 5. switch/case를 통한 타입 디스패치

엔티티 동작(타워 타겟팅, 적 능력, 상태 효과)은 문자열 타입 식별자로 키잉된 큰 `switch` 문을 통해 디스패치됩니다. 이 패턴은 시뮬레이션과 렌더링 전체에 디스패치 로직을 중복시키고 새로운 엔티티 유형을 추가할 때 오류가 발생하기 쉽게 만듭니다. 레지스트리 맵 패턴(타입 문자열 → 핸들러 함수)이 디스패치를 중앙 집중화하고 확장을 단순화합니다.
